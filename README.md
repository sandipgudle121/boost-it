# 🚀 Boost-It

Boost-It is a 3D physics-based rocket navigation game developed in Unity 6.  
Pilot your rocket through challenging obstacle-filled levels using precision movement, careful boosting, and smooth landings.

The game is inspired by classic arcade-style mechanics and focuses on player control, timing, and physics-based gameplay.

---

## 🎮 Gameplay

Your objective is simple:
- Control the rocket
- Avoid obstacles and crashes
- Reach the destination platform safely
- Complete increasingly difficult levels

Every movement matters. One wrong boost can send your rocket spinning into danger.

---

## ✨ Features

- 🚀 Physics-based rocket controls
- 🌌 Multiple challenging levels
- 💥 Collision and crash system
- 🔊 Sound effects and particle effects
- 🎯 Precision landing mechanics
- 🧱 Obstacles and environmental hazards
- ⚡ Smooth movement and responsive controls
- 🎮 Built entirely with Unity 6 and C#

---

## 🕹 Controls

| Key | Action |
|-----|--------|
| `Space` | Boost Rocket |
| `A` | Rotate Left |
| `D` | Rotate Right |
